Connect to QuickBooks Online

The CMNV Operations Toolkit is an internal-use application operated by the Treasurer of Chamber Music in Napa Valley. It is not a publicly available web application and does not offer a "Connect to QuickBooks" button to end users.

Authorization to access CMNV's QuickBooks Online company is performed once, locally, by the Treasurer using Intuit's official OAuth 2.0 flow. The flow is initiated by running the following command on the CMNV office workstation:

npm run auth

This command, provided by Intuit's official QuickBooks Online MCP Server, launches a local OAuth handshake that:

  1. Opens the Treasurer's browser to Intuit's standard authorization page (appcenter.intuit.com/connect/oauth2).
  2. Prompts the Treasurer to sign in to the CMNV QuickBooks Online company and approve the requested com.intuit.quickbooks.accounting scope.
  3. Receives the authorization code at a local callback endpoint and exchanges it for a long-lived refresh token, persisted to a local configuration file.

After this one-time authorization, the toolkit operates against CMNV's QuickBooks Online company using the stored refresh token; access tokens auto-rotate per Intuit's standard refresh flow.

For Intuit reviewers: Because this application is a single-organization internal tool with one user (the CMNV Treasurer), there is no production "Connect to QuickBooks" button suitable for end-user discovery. This page documents how connection is established. The application requests only the com.intuit.quickbooks.accounting scope.

To revoke access at any time, the QuickBooks Online administrator may disconnect the toolkit via Settings → Apps → My Apps in QuickBooks Online.
